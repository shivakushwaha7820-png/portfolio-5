SHIVA KUSHWAHA PORTFOLIO

Files:
- index.html
- style.css
- script.js
- profile.jpg

How to run:
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html with Live Server.

Profile photo:
The supplied photo is already saved as profile.jpg. Keep it in the same folder as index.html.

To deploy:
Upload/replace these files in your GitHub portfolio repository, then let Render deploy the updated site.

Note:
The contact form opens the visitor's email app. It does not store messages in a database.
